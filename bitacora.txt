1. FUNDAMENTOS HTTP (Reto 1)
----------------------------------------------------------------------
1.1 Petición del documento (DevTools > Network > index.html, Live Server)
    URL completa : http://127.0.0.1:5500/index.html
    Protocolo    : http
    Host         : 127.0.0.1 (localhost)
    Puerto       : 5500 (por defecto en Live Server)
    Ruta         : /index.html
    Método       : GET
    Código       : 200 OK
    [MEDIDO con servidor local en :5500 + curl; confirma en Headers de DevTools]

1.2 Ruta inexistente: http://127.0.0.1:5500/promociones.html
    Código  : 404 Not Found
    Significa: el servidor está bien, pero no hay recurso en esa ruta.

    200 vs 404: 200 = encontré y entrego el recurso. 404 = no existe en esa ruta.

1.3 ¿Qué pasa cuando alguien escribe la dirección del sitio? (para el cliente)
    DNS traduce el dominio a IP -> el navegador abre conexión -> envía GET con
    la ruta -> el servidor responde con código + HTML -> el navegador lee el
    HTML y pide CSS, imágenes y JS -> dibuja la página.

1.4 Roles
    HTML       : estructura y contenido. Ej.: <h1>Rueda Libre</h1>, tarjetas de flota.
    CSS        : presentación. Ej.: botón .btn-pedal naranja con texto azul noche.
    JavaScript : comportamiento. Ej.: el script que valida el formulario de reservas.

1.5 Semántica y <div>/<span>
    Se usa <header>, <nav>, <main>, <section>, <article>, <aside>, <footer>,
    <address>, <fieldset>/<legend> porque aportan significado a lectores de
    pantalla y buscadores. <div> y <span> se reservan para agrupar o marcar
    cuando NO existe una etiqueta con significado (ej.: contenedor de una promo
    del carrusel, <span class="badge"> "Nuevo").

4. PRUEBAS CSS
----------------------------------------------------------------------
4.1 Herencia: color y font-family puestos en <body> los hereda <p> sin
    reescribirlos; en cambio border o margin NO se heredan.
4.2 Especificidad: "#menu a" (id + elemento = 1,0,1) vence a ".activo"
    (clase = 0,1,0), aunque ".activo" aparezca después. Por eso en el
    proyecto se evita usar ids en CSS y se evita !important (0 en styles.css).
    Verificado: .navbar .nav-link.nav-nocturna (0,3,0) supera a .navbar .nav-link
    (0,2,0) sin !important.
4.3 Box model: content-box -> width 300px + padding 20px + borde 2px = 344px
    reales. border-box -> el ancho (300px) ya incluye padding y borde.
    Bootstrap y Tailwind aplican border-box a todo.
